    학습 기반 모델의 성능을 보증 가능한 형태로

    정답을 아는 시뮬레이션 데이터를 직접 설계해 복원 성능을 Ground-truth 기준으로 검증하는 체계를 만들었습니다(5개 환경, 10 seed 편차 0). 3D 객체 탐지에서는 점추정 대신 베이지안 샘플링으로 파라미터 불확실성을 다루는 대안을 실험했습니다.

    롱테일 상황을 찾아내고 재현하고 검증

    파라미터 중첩 · 희소 토픽 · 토픽 수 변동처럼 모델이 실패하기 쉬운 조건을 골라 검증 목적별 환경 5종으로 재현했고, 노이즈 50개 조건에서 샘플러가 무너지는 지점을 Perplexity로 정량 비교했습니다.

    차량 연산 · 메모리 안에서 경량화

    임베디드 자원 제약을 전제로 3.8B sLLM을 고르고 LoRA로 전체 파라미터의 0.01%만 조정해 응답 1.145초를 확보했습니다. QLoRA 4bit 양자화 + CAG 결합도 6종 지표로 검증했습니다.
